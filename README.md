# Barakah Box – ITE414 Group 6 E-Commerce Prototype
Static website (HTML/CSS/JS). No install needed.
## Run in VS Code (Windows)
1. Unzip, then File > Open Folder > barakah-box.
2. Install the "Live Server" extension, right-click index.html > Open with Live Server.
   (Or just double-click index.html.)
## Pages
index, catalogue, product, story, cart (cart+checkout), contact, corporate, policies.
## Features
8 products, search/filter/sort, cart (localStorage), personalised messages, checkout with Card/Apple Pay/COD (demo only), order tracking,
gift finder (personalisation), FAQs, reviews, trust badges, SEO meta + Open Graph tags, social links, mobile responsive.
## Before submission
- Replace Instagram/Facebook URLs in js/app.js footer with your real accounts.
- images/share.png is included (social share image).
- Course asks for Weebly/Shopify: rebuild the same pages there (or ask your instructor if this coded site is accepted) and reuse this content.
- Host free on GitHub Pages or Netlify to get a prototype link.

## After you host the site (important)
Search all files (VS Code: Ctrl+Shift+H) for `https://barakahbox8-max.github.io/barakah-box` and replace it with your real site address
(for example `https://yourname.github.io/barakah-box`). This fixes the social share image, canonical links, robots.txt and sitemap.xml.
Also replace the Instagram/Facebook links in the footer of every page with your real accounts.
## Images
Product pictures are illustrations in images/p1.svg ... p8.svg. Replace them with your own photos
(keep the same file names, or change the img src in js/app.js).
